# Islemetry 0.2.0

## Español

- 27 métricas locales de batería, estado térmico, CPU, memoria, almacenamiento, pantalla, red, dispositivo y sistema.
- Live Activity con vistas para pantalla bloqueada e Isla Dinámica compacta, mínima y expandida.
- Selección configurable de métricas y color de telemetría, con vista previa dentro de la app.
- Interfaz en Español, English o idioma del sistema.
- Nuevo selector de apariencia Sistema, Clara u Oscura.
- Nuevo icono, privacy manifest integrado y paquete unsigned para que AltStore Classic lo firme con la cuenta del usuario.

## English

- 27 local metrics covering battery, thermal state, CPU, memory, storage, display, network, device, and system information.
- Live Activity with Lock Screen plus compact, minimal, and expanded Dynamic Island presentations.
- Configurable metric selection and telemetry color with an in-app preview.
- Spanish, English, or system-language interface.
- New System, Light, or Dark appearance selector.
- New app icon, embedded privacy manifest, and an unsigned package for AltStore Classic to re-sign with the user's account.

## Descargas / Downloads

- `Islemetry-0.2.0.ipa`: iOS 17 o posterior, unsigned, para AltStore Classic. No es para AltStore PAL ni App Store.
- `source.json`: copia de la fuente AltStore validada para esta versión.

Fuente estable / Stable source:

```text
https://raw.githubusercontent.com/tiburonns/Islemetry/main/altstore/source.json
```

La Live Activity y la Isla Dinámica requieren validación final en un iPhone físico compatible. / The Live Activity and Dynamic Island require final validation on a compatible physical iPhone.
